Démo d'intégration — Login Kit & Content Posting API (environnement sandbox TikTok for Developers)

1Autoriser le compte TikTok (Login Kit)

Scopes demandés : user.info.basic (profil de base) et video.upload (import de brouillons). Aucune publication automatique.

2Résultat de l'autorisation

En attente — clique sur « Connecter TikTok ».

3Journal d'intégration — Content Posting API

Envois réels effectués par l'application via POST /v2/post/publish/inbox/video/init/ (vidéo importée en brouillon dans l'inbox TikTok du compte créateur).
